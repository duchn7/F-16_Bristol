# Python 4th Order Model
This folder contains the python implementation of the F-16 longitudinal model. An Object Oriented programming approach was used; to learn about the implementation 
of the NDI controller or the open loop model, see the source folder. Demo scripts were included to demonstrate the use of the open loop and closed loop classes.
The <all_data.npz> file contains the aerodynamic look up table data for the model.
## Open Loop demo
Simulates the aircraft with constant control input.
## Closed Loop demo
Simulates the aicraft as a closed loop system with an NDI controller for controlling pitch $\theta$.
